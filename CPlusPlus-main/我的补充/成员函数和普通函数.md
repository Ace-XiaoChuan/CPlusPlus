## 为什么成员函数和普通函数要区分？
    因为 类的成员函数（非静态成员函数） 背后有一个隐藏的东西 —— 它们依赖于对象（即 this 指针），而普通函数不依赖对象。
|类型|是否依赖对象？|是否有 this 指针？|
|------------|------------|---------------|
|普通函数	|❌ 不依赖对象	|❌ 没有 this
|成员函数（非静态）	|✅ 依赖对象	|✅ 有 this 指针
|静态成员函数	|❌ 不依赖对象	|❌ 没有 this

### 举例
- 普通函数
```cpp
void say_hello() {
    std::cout << "Hello\n";
}
这个函数可以直接调用：
say_hello();  // ✅ 不需要任何对象
```

- 成员函数
```cpp
成员函数（非静态）
class MyClass {
public:
    void say_hello() {
        std::cout << "Hello from MyClass\n";
    }
};
```
这个函数必须通过对象来调用：
```cpp
MyClass obj;
obj.say_hello();  // ✅ 正确
```
你不能直接写：
```cpp
say_hello();  // ❌ 编译错误：找不到函数
```

## 为什么成员函数需要对象？
因为它要访问 类的成员变量，而这些变量是对象私有的。
```cpp
class MyClass {
public:
    int number = 42;
    void print_number() {
        std::cout << number << std::endl;  // 实际是 this->number
    }
};
```
当你写 obj.print_number()，C++ 背后其实做的是：
```cpp
MyClass* this = &obj;
this->number;
```
所以每一个非静态成员函数，其实都多了一个隐藏的参数：this 指针，指向调用它的对象。

---

而在我最上面举得例子里，也是一样的道理，这里的lambda捕获了this
```cpp
    timer_ = this->create_wall_timer(
    1000ms,
    [this]() { timer_callback(); })
```
在 Lambda 中如果你要用成员函数，必须通过 [this] 捕获当前对象，才能调用成员函数。
